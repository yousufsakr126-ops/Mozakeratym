مشروع تطبيق مذاكرتي — مهام وتايمر

طريقة إنشاء APK:
1) نزّل Android Studio على الكمبيوتر.
2) فك ضغط ملف MozakeratyAndroid.zip.
3) افتح Android Studio واختر Open ثم اختر مجلد MozakeratyAndroid.
4) انتظر انتهاء Gradle Sync.
5) من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
6) بعد انتهاء البناء اضغط Locate للوصول إلى ملف APK.

ملاحظات:
- التطبيق يفتح نسخة HTML الأصلية داخل WebView.
- JavaScript وDOM Storage مفعّلان، لذلك تعمل وظائف التطبيق والتخزين المحلي.
- لا يحتاج التطبيق إلى تسجيل دخول.
- بعض الخطوط الخارجية قد تحتاج اتصال إنترنت.
